# Reversix

10×10 보드에서 두 사람이 번갈아 두는 로컬 웹게임입니다. 게임 상태는 브라우저에 저장하지 않으며 새로고침하면 새 게임으로 시작합니다.

## 실행

```sh
npm install
npm run dev
```

## 검증

```sh
npm test -- --run
npx playwright test
npm run build
```

## 규칙 요약

- 중앙의 2×2 칸에 흑·백 돌을 두 개씩 배치하고 흑부터 시작합니다. 흑의 첫 턴은 한 수이고, 이후에는 한 턴에 두 수를 두며 빈칸이 하나면 한 수만 둡니다.
- 상대 돌을 한 개 이상 양끝에서 끼워 뒤집을 수 있는 빈칸에만 착수합니다. 한 턴에 두 수를 둘 때는, 이어서 둘 수 있는 둘째 수가 남는 자리에만 첫 수를 놓을 수 있습니다. 착수할 때마다 8방향으로 둘러싼 상대 돌을 즉시 뒤집으며, 뒤집힌 돌로 연쇄 뒤집기는 하지 않습니다.
- 6개 이상 연속된 돌은 체크입니다. 체크를 받은 쪽은 턴 종료 때 상대의 모든 육목을 없애야 합니다.
- 온라인 대전, 로그인, 저장, 기보 재생은 포함되지 않습니다.

## 컴퓨터 대전

"새 게임"에서 상대를 고릅니다. 컴퓨터는 항상 흰색입니다.

| 모드 | 설명 |
|---|---|
| 2인 대전 | 한 기기에서 번갈아 둡니다 |
| 컴퓨터 · 휴리스틱 | 창(window) 포텐셜로 한 턴을 통째로 평가합니다 |
| 컴퓨터 · 학습 에이전트 | 자기대국 14,400판으로 학습한 신경망 (`rl/` 참고) |

학습 에이전트는 `public/model/iter24.{json,bin}`(1.8MB)을 불러와 브라우저에서 직접
추론합니다. BatchNorm은 내보낼 때 합성곱에 접어 넣어서, `src/game/nn.js`는 conv·relu·
잔차 덧셈만 수행합니다. 순전파 한 번에 약 66ms입니다.

착수는 학습 때와 **같은 Gumbel 탐색(시뮬 32회, 후보 16개)** 으로 고릅니다
(`src/game/search.js`, `rl/mcts.py`에서 이식). 한 수에 약 2초, 한 턴(두 수)에 약 5초가
걸리며, 탐색 도중 이벤트 루프를 양보하므로 화면은 멈추지 않고 진행 상황이 표시됩니다.

컴퓨터는 한 턴의 두 돌을 0.5초 간격으로 차례대로 놓습니다.

체크포인트를 바꾸려면:

```sh
cd rl
.venv/bin/python export_weights.py runs/r1/ck_0024.pt ../public/model/iter24.bin ../public/model/iter24.json
```

## Vercel

Vercel에서 Framework Preset을 `Vite`로 선택하고 Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. 서버 함수나 환경변수는 필요하지 않습니다.
