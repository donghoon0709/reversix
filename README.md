# Reversix

10×10 보드에서 두 사람이 번갈아 두는 로컬 웹게임입니다. 게임 상태는 브라우저에 자동으로 저장하지 않으며 새로고침하면 새 게임으로 시작합니다. 기보를 남기려면 아래처럼 파일이나 링크로 명시적으로 저장해야 합니다.

## 실행

```sh
npm install
npm run dev
```

## 검증

```sh
npm test -- --run
npx playwright test
npm run build
```

## 규칙 요약

- 중앙의 2×2 칸에 흑·백 돌을 두 개씩 배치하고 흑부터 시작합니다. 흑의 첫 턴은 한 수이고, 이후에는 한 턴에 두 수를 두며 빈칸이 하나면 한 수만 둡니다.
- 상대 돌을 한 개 이상 양끝에서 끼워 뒤집을 수 있는 빈칸에만 착수합니다. 착수할 때마다 8방향으로 둘러싼 상대 돌을 즉시 뒤집으며, 뒤집힌 돌로 연쇄 뒤집기는 하지 않습니다. 둘째 수를 둘 곳이 없으면 그 수는 생략되고 턴이 끝납니다.
- **최대 연속선이 정확히 6개**일 때만 SIX이며 체크가 됩니다. 7개 이상(오버라인)은 SIX가 아니므로, 자기 SIX를 늘리면 체크가 풀립니다.
- **금수**: 턴 시작 시점에 상대에게 없던 SIX를 만들어 주는 자리에는 둘 수 없습니다. 상대의 오버라인 끝을 뒤집으면 정확히 6개가 남아 SIX가 되기 때문입니다. 해당 칸은 🚫로 표시됩니다.
- 체크를 받은 쪽은 다음 한 턴 안에 체크를 건 색의 SIX를 모두 없애야 합니다. 방어 실패 판정이 다른 모든 판정보다 우선합니다.
- 첫 착수가 없으면 패스합니다. 체크 중 패스는 패배이고, 체크가 없는 상태에서 연속 두 번 패스하면 돌 개수로 승패·무승부를 정합니다.
- 온라인 대전과 로그인은 포함되지 않습니다.

## 컴퓨터 대전

"새 게임"에서 상대를 고르고, 컴퓨터 상대라면 이어서 선공·후공을 고릅니다.

| 모드 | 설명 |
|---|---|
| 2인 대전 | 한 기기에서 번갈아 둡니다 |
| 컴퓨터 · 휴리스틱 | 창(window) 포텐셜로 한 턴을 통째로 평가합니다 |
| 컴퓨터 · 학습 에이전트 | 자기대국으로 학습한 신경망 (`rl/` 참고). 가중치가 없으면 이 선택지는 비활성화됩니다 |

후공을 고르면 컴퓨터가 검은색을 잡고 먼저 둡니다.

학습 에이전트는 `public/model/latest.{json,bin}`(1.8MB)을 불러와 브라우저에서 직접
추론합니다. BatchNorm은 내보낼 때 합성곱에 접어 넣어서, `src/game/nn.js`는 conv·relu·
잔차 덧셈만 수행합니다. 순전파 한 번에 약 66ms입니다.

착수는 학습 때와 **같은 Gumbel 탐색(시뮬 32회, 후보 16개)** 으로 고릅니다
(`src/game/search.js`, `rl/mcts.py`에서 이식). 한 수에 약 2초, 한 턴(두 수)에 약 5초가
걸리며, 탐색 도중 이벤트 루프를 양보하므로 화면은 멈추지 않고 진행 상황이 표시됩니다.

컴퓨터는 한 턴의 두 돌을 0.5초 간격으로 차례대로 놓습니다.

체크포인트를 바꾸려면:

```sh
cd rl
.venv/bin/python export_weights.py runs/r3/latest.pt ../public/model/latest.bin ../public/model/latest.json
```

## 기보

진행 중이거나 끝난 게임을 텍스트 파일 또는 링크로 저장할 수 있습니다.

텍스트 파일은 PGN과 비슷한 형식입니다:

```
[Format "reversix"]
[Version "1"]
[Date "2026-09-09"]
[Mode "net"]
[Human "BLACK"]

1. E5 2. D6 F4 3. -- 4. C3 C4+ 5. G7 H8# 1-0
```

턴 번호는 1부터 시작하고, `--`는 패스, `+`는 체크를 건 턴, `#`은 끝난 게임의 마지막 수를 뜻합니다. 마지막 토큰은 결과로 `1-0`은 흑 승, `0-1`은 백 승, `1/2-1/2`는 무승부, `*`는 진행 중을 뜻합니다.

링크로 저장하면 `?g=` 뒤에 base64url 토큰이 붙습니다. 80수짜리 게임 기준 108자 안팎입니다.

기보를 감상하려면 "새 게임"에서 "기보 감상"을 고르고 파일을 올리거나 텍스트를 붙여 넣습니다. `?g=` 링크를 열면 바로 감상 화면으로 이동합니다. 감상 보드는 읽기 전용이며 처음·이전·다음·마지막 버튼으로, 또는 보드에 포커스가 있을 때 좌우 화살표와 Home·End 키로 한 수씩 이동합니다. 감상 중 착수하거나 감상한 위치에서 대국을 이어가는 기능은 없습니다.

기보에는 착수한 칸의 순서만 저장됩니다. 턴 경계와 패스는 저장하지 않는데, 규칙 엔진이 이미 그 정보를 알고 있기 때문입니다 — 둘 곳이 없는 쪽은 패스하고, 첫 수 다음에 둘 곳이 없으면 그 턴은 한 수로 끝나고, 그 외에는 한 턴이 두 수입니다. 그래서 저장된 칸들을 실제 대국과 같은 리듀서에 그대로 흘려보내면 게임 전체가 재구성되며, 기보가 규칙과 어긋날 수 없습니다. 패스는 저장 공간을 전혀 쓰지 않고, `+`·`#`·결과 토큰도 저장 시점에 계산되어 불러올 때 다시 검증될 뿐 그대로 신뢰되지 않습니다.

## Vercel

Vercel에서 Framework Preset을 `Vite`로 선택하고 Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. 서버 함수나 환경변수는 필요하지 않습니다.
