# Reversix

15×15 보드에서 두 사람이 번갈아 두는 로컬 웹게임입니다. 게임 상태는 브라우저에 저장하지 않으며 새로고침하면 새 게임으로 시작합니다.

## 실행

```sh
npm install
npm run dev
```

## 검증

```sh
npm test -- --run
npx playwright test
npm run build
```

## 규칙 요약

- 흑은 빈 보드에서 첫 턴에 한 수를 둡니다. 이후에는 한 턴에 두 수를 두며, 빈칸이 하나면 한 수만 둡니다.
- 착수할 때마다 8방향으로 둘러싸인 상대 돌을 즉시 뒤집습니다. 뒤집힌 돌로 연쇄 뒤집기는 하지 않습니다.
- 같은 턴의 두 돌이 양끝이 되고, 첫 수의 뒤집기를 반영한 보드에서 그 사이에 상대 돌이 끊기지 않고 4개 이상 있으면 둘째 수는 금수입니다.
- 6개 이상 연속된 돌은 체크입니다. 체크를 받은 쪽은 턴 종료 때 상대의 모든 육목을 없애야 합니다.
- 온라인 대전, AI, 로그인, 저장, 기보 재생은 이 MVP에 포함되지 않습니다.

## Vercel

Vercel에서 Framework Preset을 `Vite`로 선택하고 Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다. 서버 함수나 환경변수는 필요하지 않습니다.
